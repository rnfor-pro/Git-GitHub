# Git and GitHub for Beginners: From Zero to Pull Requests

> A complete, hands-on beginner course for DevOps, cloud, and software engineering students.

---

## Who Is This Course For?

This course is built for students who are new to Git, GitHub, and the command line. You do not need any prior experience with version control. If you have ever accidentally overwritten a file and wished you could go back, this course is for you.

Whether you are starting a career in DevOps, cloud engineering, software development, or IT, understanding Git and GitHub is one of the most important job-ready skills you can have.

---

## What You Will Learn

By the end of this course, you will be able to:

- Explain what Git is and why teams use it
- Create and configure a GitHub account with SSH authentication
- Create, clone, and manage repositories
- Track changes using commits
- Work with branches like a professional developer
- Submit and review pull requests
- Apply branch protection rules
- Collaborate inside a GitHub organization
- Follow a real DevOps team workflow (DEV → UAT → MAIN)
- Use VS Code for Git tasks
- Complete a solo project from branch to merged pull request

---

## Prerequisites

No Git or GitHub experience needed. Students should be able to:

- Use a computer and a web browser
- Open a terminal or command line
- Type commands when instructed

## Final Project Overview

Students will:
1. Clone the class repository
2. Create a personal branch (`feature/firstname-lastname-profile`)
3. Update the `README.md` with their name and introduction
4. Create a file inside a `dir1/` folder
5. Stage, commit, and push their changes
6. Open a pull request and request a review
7. Merge after approval

The final project is graded out of 100 points. See [`labs/final-project.md`](labs/final-project.md) for the rubric.
