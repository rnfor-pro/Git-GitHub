# Lab 01: Create a GitHub Account

**Estimated Time:** 15 minutes  
**Prerequisites:** Internet access, email address  

---

## Objective

Create and configure a GitHub account that you will use throughout this entire course.

## What You Will Learn

- How to create a GitHub account
- How to choose a professional username
- How to set a profile picture and bio

---

## Step-by-Step Instructions

### Step 1: Go to GitHub

Open your browser and navigate to [https://github.com](https://github.com).

### Step 2: Sign Up

Click **Sign up** and follow the prompts:
- Enter your **email address** (use the same one you will use for Git config)
- Choose a **password**
- Choose a **username**

> **Choosing a username:** This will appear on your commits and public profile. Pick something professional — ideally your real name or a variation of it. Examples: `jane-smith`, `jsmith-dev`, `john-doe`. Avoid names like `xXcoderXx2024`.

### Step 3: Verify Your Email

GitHub will send a verification email. Open it and click the verification link.

### Step 4: Complete Setup

GitHub may ask a few onboarding questions. Answer or skip them as you prefer.

### Step 5: View Your Profile

Click your profile picture in the top right → **Your profile**.

You should see your new GitHub profile page at `github.com/your-username`.

---

## Optional: Set Up Your Profile

A complete profile looks more professional. Go to **Settings → Public profile** and consider adding:
- A profile photo
- Your full name
- A short bio (example: "DevOps student | Learning Git and GitHub")
- Your location

---

## Checkpoint Questions

1. What is your GitHub username?
2. What URL does your public profile appear at?
3. Is the email on your GitHub account the same one you plan to use for `git config`?
