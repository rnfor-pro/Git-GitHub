## Submission Checklist

Complete each item and check the box before submitting your pull request.

### Branch and Repository

- [ ] I cloned the class repository (not my own)
- [ ] My branch name follows the convention: `feature/firstname-lastname-profile`
- [ ] I am working on my feature branch, NOT on `main`

### Files Created and Modified

- [ ] I updated `README.md` with my name
- [ ] I added at least 2 sentences of introduction in `README.md`
- [ ] I created a file inside the `dir1/` folder (not in the root)
- [ ] The file in `dir1/` contains meaningful content (not just blank or "test")

### Git Workflow

- [ ] I ran `git status` and confirmed only my intended files were staged
- [ ] I committed with a meaningful message (not "update" or "changes")
- [ ] I ran `git log --oneline` and confirmed my commit is there
- [ ] I pushed my branch: `git push -u origin feature/my-branch`
- [ ] My branch appears on GitHub (I can see it in the branch list)

### Pull Request

- [ ] I opened a pull request from my branch to `main`
- [ ] My PR title clearly describes the change
- [ ] I filled in the PR description using the template
- [ ] I assigned my instructor as reviewer
- [ ] I have not merged without approval
